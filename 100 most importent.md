### **1. Fundamentals of Data Structures (Prerequisite)**
Before diving into advanced DSA, ensure that you have a strong understanding of basic data structures and algorithms:

- **Arrays**: Basic operations, searching, sorting.
- **Linked Lists**: Singly, doubly, and circular linked lists.
- **Stacks and Queues**: Operations, applications, and implementation.
- **Hashing**: Hash tables, hash maps, collisions, and handling them.
- **Trees**: Binary trees, binary search trees (BST), and tree traversals.
- **Graphs**: Representation, traversal algorithms (BFS, DFS).
- **Heaps**: Min-heap and max-heap operations.

### **2. Sorting and Searching Algorithms**
Start with sorting and searching algorithms, as they are the foundation of many advanced algorithms.

- **Basic Sorting Algorithms**:
  - **Bubble Sort**, **Selection Sort**, **Insertion Sort** (O(n^2) time complexity)
  - **Merge Sort** and **Quick Sort** (O(n log n) time complexity)
- **Advanced Sorting**:
  - **Heap Sort**: Uses heaps (O(n log n) time complexity).
  - **Counting Sort**, **Radix Sort**, **Bucket Sort** (O(n) time complexity in specific conditions).
- **Binary Search**: Understand binary search and its applications in searching, finding the lower/upper bound, etc.

### **3. Dynamic Programming (DP)**
Dynamic programming is one of the most important topics in DSA. Focus on solving problems using bottom-up and top-down approaches.

- **Theory**: Overlapping subproblems and optimal substructure.
- **Key DP Problems**:
  - **0/1 Knapsack Problem**
  - **Longest Common Subsequence (LCS)**
  - **Longest Increasing Subsequence (LIS)**
  - **Coin Change Problem**
  - **Rod Cutting Problem**
  - **Matrix Chain Multiplication**
  - **Palindrome Partitioning**
  - **Edit Distance**

### **4. Divide and Conquer**
Divide and conquer techniques break the problem into smaller subproblems, solve them recursively, and then combine the results.

- **Theory**: Recursion, and solving subproblems independently.
- **Key Problems**:
  - **Merge Sort**, **Quick Sort**
  - **Binary Search**
  - **Closest Pair of Points**
  - **K-th Smallest Element**

### **5. Greedy Algorithms**
Greedy algorithms make locally optimal choices at each step with the hope of finding a global optimum.

- **Theory**: Greedy choice property and optimal substructure.
- **Key Problems**:
  - **Activity Selection Problem**
  - **Huffman Coding**
  - **Kruskal’s Algorithm**
  - **Prim’s Algorithm**
  - **Fractional Knapsack Problem**

### **6. Graph Algorithms**
Graph problems are critical for advanced DSA. Study both directed and undirected graph algorithms thoroughly.

- **Theory**:
  - **Graph Representation**: Adjacency matrix and adjacency list.
  - **Graph Traversal**: BFS, DFS.
  - **Shortest Path Algorithms**:
    - **Dijkstra’s Algorithm**
    - **Bellman-Ford Algorithm**

### **7. Advanced Trees**
Trees, especially binary trees and advanced variations like AVL and Red-Black Trees, are central to many complex problems.

### **1. Find the missing number in an array of 1 to n**

#### **Concept:**
This problem involves finding a missing number from a sequence of integers ranging from `1` to `n`. Common concepts used here are:

1. **Summation Formula**: The sum of the first `n` natural numbers is \((n \times (n+1)) / 2\).
2. **Bit Manipulation**: XOR can also be used to find the missing number efficiently.
3. **Hashing**: A hash set or dictionary can track the presence of numbers.

#### **Python Solutions:**

**Solution 1: Summation Formula**
```python
def find_missing_number(nums):
    n = len(nums) + 1  # Total numbers including the missing one
    total_sum = n * (n + 1) // 2
    actual_sum = sum(nums)
    return total_sum - actual_sum

# Example
nums = [1, 2, 4, 5, 6]
print(find_missing_number(nums))  # Output: 3
```

**Solution 2: XOR Method**
```python
def find_missing_number(nums):
    n = len(nums) + 1
    xor_all = 0
    xor_array = 0
    
    for i in range(1, n + 1):
        xor_all ^= i  # XOR of all numbers from 1 to n
    
    for num in nums:
        xor_array ^= num  # XOR of numbers in the array
    
    return xor_all ^ xor_array

# Example
nums = [1, 2, 4, 5, 6]
print(find_missing_number(nums))  # Output: 3
```

**Solution 3: Hashing**
```python
def find_missing_number(nums):
    num_set = set(nums)
    n = len(nums) + 1
    for i in range(1, n + 1):
        if i not in num_set:
            return i

# Example
nums = [1, 2, 4, 5, 6]
print(find_missing_number(nums))  # Output: 3
```

### **2. Kadane's Algorithm (Maximum Subarray Sum)**

#### **Concept:**
Kadane's Algorithm efficiently finds the maximum sum of a contiguous subarray using dynamic programming. The idea is to iterate through the array while maintaining a running sum, updating the maximum sum when the running sum exceeds it, and resetting the running sum to zero if it becomes negative.

#### **Python Solution:**
```python
def max_subarray_sum(nums):
    max_sum = float('-inf')  # Initialize to negative infinity
    current_sum = 0
    
    for num in nums:
        current_sum = max(num, current_sum + num)
        max_sum = max(max_sum, current_sum)
    
    return max_sum

# Example
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
print(max_subarray_sum(nums))  # Output: 6 (subarray: [4, -1, 2, 1])
```

### **3. Find Duplicate Numbers in an Array**

#### **Concept:**

- **Hashing**: Use a hash set to detect duplicates.
- **Index Marking**: Modify the array itself (marking visited indices as negative).

```python
def find_duplicates(nums):
    nums.sort()
    duplicates = []
    for i in range(1, len(nums)):
        if nums[i] == nums[i - 1]:
            duplicates.append(nums[i])
    return duplicates
```

```python
def find_duplicates(nums):

    duplicates = []
    for num in nums:
```

### **4. Merge Two Sorted Arrays Without Extra Space**

#### **Concept:**
- Use **two-pointer technique** to merge arrays in place.
- Start comparing elements from the end of both arrays.

#### **Python Solution:**
```python
def merge(nums1, nums2):
    m, n = len(nums1), len(nums2)
    i, j, k = m - 1, n - 1, m + n - 1  # Start from the end
    
    nums1.extend([0] * n)  # Extend nums1 to accommodate nums2
    while j >= 0:
        if i >= 0 and nums1[i] > nums2[j]:
            nums1[k] = nums1[i]
            i -= 1
        else:
            nums1[k] = nums2[j]
            j -= 1
        k -= 1
    
    return nums1

# Example
nums1 = [1, 2, 3]
nums2 = [2, 5, 6]
print(merge(nums1, nums2))  # Output: [1, 2, 2, 3, 5, 6]
```

```python
def rotate(nums, k):
    k %= len(nums)
    nums[:] = nums[::-1]
    nums[:k] = nums[:k][::-1]
    nums[k:] = nums[k:][::-1]

rotate(nums, 3)
```

**Solution 2: Cyclic Replacements**
```python
def rotate(nums, k):
    n = len(nums)
    k %= n
    count = 0
    
    for start in range(n):
        if count >= n:
            break
        current, prev = start, nums[start]
        while True:
            next_idx = (current + k) % n
            nums[next_idx], prev = prev, nums[next_idx]
            current = next_idx
            count += 1
            if start == current:
                break

# Example
nums = [1, 2, 3, 4, 5, 6, 7]
rotate(nums, 3)
print(nums)  # Output: [5, 6, 7, 1, 2, 3, 4]
```

### **6. Find All Pairs in an Array That Sum Up to a Given Number**

- Use **two-pointer technique** on a sorted array.
- Use **hashing** to track complements.

#### **Python Solutions:**

**Solution 1: Hashing**

```python
def find_pairs(nums, target):
    seen = set()
    pairs = []
    for num in nums:
        complement = target - num
        if complement in seen:
            pairs.append((num, complement))
        seen.add(num)
    return pairs

# Example

target = 7
print(find_pairs(nums, target))  # Output: [(6, 1), (5, 2), (4, 3)]
```

```python
def find_pairs(nums, target):
    nums.sort()
    left, right = 0, len(nums) - 1
    pairs = []
    while left < right:
        s = nums[left] + nums[right]
        if s == target:
            pairs.append((nums[left], nums[right]))
            left += 1
            right -= 1
        elif s < target:
            left += 1
        else:
            right -= 1
    return pairs

# Example
```

### **7. Trapping Rain Water**

#### **Concept:**
- Use **two-pointer technique** to calculate water trapped between walls.
- Calculate **prefix and suffix arrays** to track max heights.

#### **Python Solutions:**

**Solution 1: Two-Pointer Technique**
```python
def trap(height):
    left, right = 0, len(height) - 1
    left_max, right_max = 0, 0
    water = 0
    
    while left < right:
        if height[left] < height[right]:
            if height[left] >= left_max:
                left_max = height[left]
            else:
                water += left_max - height[left]
            left += 1
        else:
            if height[right] >= right_max:
                right_max = height[right]
            else:
                water += right_max - height[right]
            right -= 1
    
    return water

# Example
height = [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]
print(trap(height))  # Output: 6
```

**Solution 2: Prefix-Suffix Arrays**
```python
def trap(height):
    n = len(height)
    if n == 0:
        return 0
    
    left_max = [0] * n
    right_max = [0] * n
    water = 0
    
    left_max[0] = height[0]
    for i in range(1, n):
        left_max[i] = max(left_max[i - 1], height[i])
    
    right_max[n - 1] = height[n - 1]
    for i in range(n - 2, -1, -1):
        right_max[i] = max(right_max[i + 1], height[i])
    
    for i in range(n):
        water += min(left_max[i], right_max[i]) - height[i]
    
    return water

# Example
height = [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]
print(trap(height))  # Output: 6
```

```python
def longest_consecutive(nums):
    if not nums:
        return 0
    
    nums = sorted(set(nums))
```

### **9. Find the Majority Element**

- Use **Boyer-Moore Voting Algorithm** for O(n) time and O(1) space.
- Use **hashing** for counting occurrences.

#### **Python Solutions:**

**Solution 1: Boyer-Moore Voting Algorithm**
```python
def majority_element(nums):
    count, candidate = 0, None
    
    for num in nums:
        if count == 0:
            candidate = num
        count += (1 if num == candidate else -1)
    
    return candidate

# Example

print(majority_element(nums))  # Output: 3
```

```python
def max_profit(prices):
```

```python
def merge_intervals(intervals):
    intervals.sort(key=lambda x: x[0])
```

### **12. Next Permutation of an Array**

#### **Concept:**
- Traverse from the end to find the first decreasing element.
- Swap it with the next larger element and reverse the remaining array.

#### **Python Solution:**
```python
def next_permutation(nums):
    n = len(nums)
    i = n - 2
    
    # Find the first decreasing element
    while i >= 0 and nums[i] >= nums[i + 1]:
        i -= 1
    
    if i >= 0:
        # Find the next larger element
        j = n - 1
        while nums[j] <= nums[i]:
            j -= 1
        nums[i], nums[j] = nums[j], nums[i]
    
    # Reverse the elements to the right of i
    nums[i + 1:] = reversed(nums[i + 1:])
    return nums

# Example
nums = [1, 2, 3]
print(next_permutation(nums))  # Output: [1, 3, 2]
```

### **13. Find the Minimum Number of Platforms Required for a Train Station**

#### **Concept:**
- Use a **sweep line algorithm** with sorted arrival and departure times to track platform occupancy.

#### **Python Solution:**
```python
def min_platforms(arrivals, departures):
    arrivals.sort()
    departures.sort()
    
    platforms_needed, max_platforms = 0, 0
    i, j = 0, 0
    
    while i < len(arrivals):
        if arrivals[i] < departures[j]:
            platforms_needed += 1
            max_platforms = max(max_platforms, platforms_needed)
            i += 1
        else:
            platforms_needed -= 1
            j += 1
    
    return max_platforms

# Example
arrivals = [900, 940, 950, 1100, 1500, 1800]
departures = [910, 1200, 1120, 1130, 1900, 2000]
print(min_platforms(arrivals, departures))  # Output: 3
```

### **14. Maximum Product Subarray**

#### **Concept:**
- Track the maximum and minimum product at each step (since negatives can flip signs).

#### **Python Solution:**

```python
def max_product(nums):
    max_prod, min_prod, result = nums[0], nums[0], nums[0]
    
    for i in range(1, len(nums)):
        if nums[i] < 0:
            max_prod, min_prod = min_prod, max_prod
        max_prod = max(nums[i], max_prod * nums[i])
        min_prod = min(nums[i], min_prod * nums[i])
        result = max(result, max_prod)
    
    return result

# Example
```

### **15. Find Subarray with Given Sum**

#### **Concept:**
- Use **sliding window** for positive arrays.
- Use **hashing** for arrays with negative numbers.

#### **Python Solutions:**

**Solution 1: Sliding Window**
```python
def subarray_sum(nums, target):
    start, current_sum = 0, 0
    
    for end in range(len(nums)):
        current_sum += nums[end]
        while current_sum > target:
            current_sum -= nums[start]
            start += 1
        if current_sum == target:
            return nums[start:end + 1]
    
    return []

# Example
nums = [1, 2, 3, 7, 5]
target = 12
print(subarray_sum(nums, target))  # Output: [2, 3, 7]
```

**Solution 2: Hashing**
```python
def subarray_sum(nums, target):
    prefix_sum = {0: -1}
    current_sum = 0
    
    for i, num in enumerate(nums):
        current_sum += num
        if current_sum - target in prefix_sum:
            return nums[prefix_sum[current_sum - target] + 1:i + 1]
        prefix_sum[current_sum] = i
    
    return []

# Example
nums = [10, 15, -5, 15, -10, 5]
target = 5
print(subarray_sum(nums, target))  # Output: [15, -10]
```

### **16. Find Median of Two Sorted Arrays**

```python
def find_median_sorted_arrays(nums1, nums2):
    A, B = nums1, nums2
    if len(A) > len(B):
        A, B = B, A
    m, n = len(A), len(B)
    imin, imax, half_len = 0, m, (m + n + 1) // 2
    
    while imin <= imax:
        i = (imin + imax) // 2
        j = half_len - i
        if i < m and B[j - 1] > A[i]:
            imin = i + 1
        elif i > 0 and A[i - 1] > B[j]:
            imax = i - 1
        else:
            max_of_left = max(A[i - 1] if i > 0 else float('-inf'),
                              B[j - 1] if j > 0 else float('-inf'))
            if (m + n) % 2 == 1:
                return max_of_left
            
            min_of_right = min(A[i] if i < m else float('inf'),
                               B[j] if j < n else float('inf'))
            return (max_of_left + min_of_right) / 2

# Example

nums2 = [2]
print(find_median_sorted_arrays(nums1, nums2))  # Output: 2.0
```

### **22. Z-Algorithm (Pattern Matching)**

#### **Problem Description:**
Find all occurrences of a pattern in a string using the Z-Algorithm.

#### **Concept:**
- Compute the Z-array for the concatenated string `pattern + '$' + text`.
- A match occurs at indices where Z-values equal the pattern length.

#### **Python Solution:**
```python
def z_algorithm(pattern, text):
    concat = pattern + "$" + text
    z = [0] * len(concat)
    l, r = 0, 0
    
    for i in range(1, len(concat)):
        if i <= r:
            z[i] = min(r - i + 1, z[i - l])
        while i + z[i] < len(concat) and concat[z[i]] == concat[i + z[i]]:
            z[i] += 1
        if i + z[i] - 1 > r:
            l, r = i, i + z[i] - 1
    
    return [i - len(pattern) - 1 for i in range(len(pattern) + 1, len(concat)) if z[i] == len(pattern)]
```

### **23. KMP Algorithm for Pattern Matching**

#### **Problem Description:**
Find all occurrences of a pattern in a string using the Knuth-Morris-Pratt (KMP) algorithm.

#### **Concept:**
- Precompute the LPS (Longest Prefix Suffix) array for the pattern.
- Use the LPS array to avoid redundant comparisons.

#### **Python Solution:**
```python
def kmp_algorithm(pattern, text):
    def compute_lps(pattern):
        lps = [0] * len(pattern)
        length = 0
        i = 1
        
        while i < len(pattern):
            if pattern[i] == pattern[length]:
                length += 1
                lps[i] = length
                i += 1
            elif length != 0:
                length = lps[length - 1]
            else:
                lps[i] = 0
                i += 1
        
        return lps
    
    lps = compute_lps(pattern)
    i, j = 0, 0
    result = []
    
    while i < len(text):
        if pattern[j] == text[i]:
            i += 1
            j += 1
        
        if j == len(pattern):
            result.append(i - j)
            j = lps[j - 1]
        elif i < len(text) and pattern[j] != text[i]:
            if j != 0:
                j = lps[j - 1]
            else:
                i += 1
    
    return result
```

### **27. Rabin-Karp Algorithm**

#### **Problem Description:**
Find all occurrences of a pattern in a string using the Rabin-Karp algorithm, which relies on hashing.

#### **Concept:**
- Compute a rolling hash for the text and compare it with the hash of the pattern.
- Hash collisions are handled by directly comparing substrings.

#### **Python Solution:**
```python
def rabin_karp(pattern, text, prime=101):
    m, n = len(pattern), len(text)
    pattern_hash = 0
    text_hash = 0
    h = 1
    result = []
    
    for i in range(m - 1):
        h = (h * 256) % prime
    
    for i in range(m):
        pattern_hash = (256 * pattern_hash + ord(pattern[i])) % prime
        text_hash = (256 * text_hash + ord(text[i])) % prime
    
    for i in range(n - m + 1):
        if pattern_hash == text_hash:
            if text[i:i + m] == pattern:
                result.append(i)
        
        if i < n - m:
            text_hash = (256 * (text_hash - ord(text[i]) * h) + ord(text[i + m])) % prime
            if text_hash < 0:
                text_hash += prime
    
    return result

# Example

```

```python
        self.q1, self.q2 = self.q2, self.q1

    def is_empty(self):
        return not self.q1
```

### **44. Min Stack (O(1) Space for Minimum Element)**

```python
        self.stack = []
        self.min_element = None

    def push(self, x):
        if not self.stack:
            self.stack.append(0)
            self.min_element = x
        else:
            self.stack.append(x - self.min_element)
            if x < self.min_element:
                self.min_element = x

        if not self.stack:
            return None
        top = self.stack.pop()
        if top < 0:
            self.min_element -= top

    def top(self):
        top = self.stack[-1]
        return self.min_element if top < 0 else self.min_element + top

    def get_min(self):
        return self.min_element
```

### **46. LRU Cache Implementation**

#### **Problem Description:**
Design a data structure for an LRU (Least Recently Used) cache.

#### **Concept:**
- Use `OrderedDict` from the `collections` module to implement the LRU cache.

#### **Python Solution:**
```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        self.cache = OrderedDict()
        self.capacity = capacity

    def get(self, key):
        if key in self.cache:
            self.cache.move_to_end(key)
            return self.cache[key]
        return -1

    def put(self, key, value):
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
```

### **47. Sliding Window Maximum**

#### **Problem Description:**
Find the maximum value in each sliding window of size `k` in an array.

#### **Concept:**
- Use a deque to store indices of useful elements in the window.

#### **Python Solution:**
```python
from collections import deque

def max_sliding_window(nums, k):
    dq = deque()
    result = []

    for i in range(len(nums)):
        if dq and dq[0] < i - k + 1:
            dq.popleft()

        while dq and nums[dq[-1]] < nums[i]:
            dq.pop()

        dq.append(i)
        if i >= k - 1:
            result.append(nums[dq[0]])

    return result
```

### **65. Find the Median from a Data Stream**

#### **Problem Description:**
Find the median of a data stream, where numbers are continuously added.

#### **Concept:**
- Use two heaps: a max-heap for the lower half and a min-heap for the upper half of the numbers.

#### **Python Solution:**
```python
import heapq

class MedianFinder:
    def __init__(self):
        self.max_heap = []  # Max heap for lower half (invert values to use heapq as max-heap)
        self.min_heap = []  # Min heap for upper half
    
    def add_num(self, num):
        heapq.heappush(self.max_heap, -num)  # Add to max heap (invert value)
        if len(self.max_heap) > len(self.min_heap) + 1:
            heapq.heappush(self.min_heap, -heapq.heappop(self.max_heap))  # Balance heaps
        
        if self.min_heap and -self.max_heap[0] > self.min_heap[0]:
            heapq.heappush(self.max_heap, -heapq.heappop(self.min_heap))
            heapq.heappush(self.min_heap, -self.max_heap[0])
    
    def find_median(self):
        if len(self.max_heap) > len(self.min_heap):
            return -self.max_heap[0]
        return (-self.max_heap[0] + self.min_heap[0]) / 2
```

### **73. Topological Sort**

#### **Problem Description:**
Given a Directed Acyclic Graph (DAG), perform a topological sort (order of nodes such that for every directed edge u -> v, u comes before v).

#### **Concept:**
- Use DFS with post-order traversal or Kahn’s algorithm (BFS-based approach).

#### **Python Solution:**
```python
from collections import defaultdict, deque

def topological_sort(graph):
    indegree = defaultdict(int)
    for node in graph:
        for neighbor in graph[node]:
            indegree[neighbor] += 1

    queue = deque([node for node in graph if indegree[node] == 0])
    result = []
    
    while queue:
        node = queue.popleft()
        result.append(node)
        for neighbor in graph[node]:
            indegree[neighbor] -= 1
            if indegree[neighbor] == 0:
                queue.append(neighbor)

    if len(result) == len(graph):
        return result
    return []  # Return empty if there is a cycle (not a DAG)

# Example
graph = {0: [1, 2], 1: [3], 2: [3], 3: []}
print(topological_sort(graph))  # Output: [0, 2, 1, 3]
```

### **74. Dijkstra's Algorithm**

#### **Problem Description:**
Find the shortest path from a source node to all other nodes in a weighted graph.

#### **Concept:**
- Use a priority queue (min-heap) to select the node with the smallest tentative distance and update its neighbors.

#### **Python Solution:**
```python
import heapq

def dijkstra(graph, source):
    distances = {node: float('inf') for node in graph}
    distances[source] = 0
    pq = [(0, source)]
    
    while pq:
        current_dist, current_node = heapq.heappop(pq)
        
        if current_dist > distances[current_node]:
            continue
        
        for neighbor, weight in graph[current_node]:
            distance = current_dist + weight
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(pq, (distance, neighbor))
    
    return distances

# Example

source = 0
print(dijkstra(graph, source))  # Output: {0: 0, 1: 3, 2: 1, 3: 4}
```

### **75. Bellman-Ford Algorithm**

#### **Problem Description:**
Find the shortest path from a source node to all other nodes, handling negative weight edges. Detect negative weight cycles.

#### **Concept:**
- Relax all edges for (V - 1) times, and check for negative weight cycles in the Vth iteration.

#### **Python Solution:**
```python
def bellman_ford(graph, V, source):
    distances = {i: float('inf') for i in range(V)}
    distances[source] = 0
    
    for _ in range(V - 1):
        for u, v, weight in graph:
            if distances[u] + weight < distances[v]:
                distances[v] = distances[u] + weight
    
    for u, v, weight in graph:
        if distances[u] + weight < distances[v]:
            return "Graph contains negative weight cycle"
    
    return distances

# Example
```

### **76. Kruskal's Algorithm**

#### **Problem Description:**
Find the Minimum Spanning Tree (MST) of a graph using Kruskal’s algorithm.

#### **Concept:**
- Sort all edges by weight and add them to the MST if they don’t form a cycle (using union-find).

#### **Python Solution:**
```python
class DisjointSet:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        rootX = self.find(x)
        rootY = self.find(y)
        
        if rootX != rootY:
            if self.rank[rootX] > self.rank[rootY]:
                self.parent[rootY] = rootX
            elif self.rank[rootX] < self.rank[rootY]:
                self.parent[rootX] = rootY
            else:
                self.parent[rootY] = rootX
                self.rank[rootX] += 1

def kruskal(graph, V):
    edges = sorted(graph, key=lambda x: x[2])
    ds = DisjointSet(V)
    mst = []
    
    for u, v, weight in edges:
        if ds.find(u) != ds.find(v):
            ds.union(u, v)
            mst.append((u, v, weight))
    
    return mst

# Example
graph = [(0, 1, 10), (0, 2, 6), (0, 3, 5), (1, 3, 15), (2, 3, 4)]
V = 4
print(kruskal(graph, V))  # Output: [(2, 3, 4), (0, 3, 5), (0, 1, 10)]
```

### **77. Prim's Algorithm**

#### **Problem Description:**
Find the Minimum Spanning Tree (MST) of a graph using Prim’s algorithm.

#### **Concept:**
- Use a priority queue (min-heap) to add the minimum weight edge that connects a vertex in the MST to a vertex outside the MST.

#### **Python Solution:**
```python
import heapq

def prim(graph, V):
    mst = []
    visited = [False] * V
    min_heap = [(0, 0)]  # (weight, node)
    
    while min_heap:
        weight, u = heapq.heappop(min_heap)
        
        if visited[u]:
            continue
        
        visited[u] = True
        mst.append((u, weight))
        
        for v, w in graph[u]:
            if not visited[v]:
                heapq.heappush(min_heap, (w, v))
    
    return mst[1:]  # Exclude the starting node

# Example
```

### **81. 0/1 Knapsack Problem**

#### **Problem Description:**

#### **Concept:**
- Use dynamic programming to solve by building a DP table where `dp[i][w]` represents the maximum value that can be obtained with the first `i` items and a knapsack capacity of `w`.

#### **Python Solution:**
```python
def knapsack(weights, values, capacity):
    n = len(weights)
    dp = [[0 for _ in range(capacity + 1)] for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        for w in range(capacity + 1):
            if weights[i-1] <= w:
                dp[i][w] = max(values[i-1] + dp[i-1][w - weights[i-1]], dp[i-1][w])
            else:
                dp[i][w] = dp[i-1][w]
    
    return dp[n][capacity]
```

```python
    inv_count += merge(arr, temp_arr, left, mid, right)
    return inv_count

def merge(arr, temp_arr, left, mid, right):
    i = left    # Starting index for left subarray
    j = mid + 1 # Starting index for right subarray
    k = left    # Starting index to be sorted
    inv_count = 0
    
    while i <= mid and j <= right:
        if arr[i] <= arr[j]:
            temp_arr[k] = arr[i]
            i += 1
        else:
            temp_arr[k] = arr[j]
            inv_count += (mid - i + 1)
            j += 1
        k += 1
    
    while i <= mid:
        temp_arr[k] = arr[i]
        i += 1
        k += 1
    
    while j <= right:
        temp_arr[k] = arr[j]
        j += 1
        k += 1
    
    for i in range(left, right + 1):
        arr[i] = temp_arr[i]
    
    return inv_count

def count_inversions(arr):
    n = len(arr)
    temp_arr = [0] * n
    return merge_count(arr, temp_arr, 0, n - 1)

# Example
arr = [1, 20, 6, 4, 5]
print(count_inversions(arr))  # Output: 5
```

### **100. N-Queens Problem**

#### **Problem Description:**
The N-Queens puzzle is the problem of placing `n` queens on an `n × n` chessboard such that no two queens threaten each other. A queen can attack another queen if they are on the same row, column, or diagonal.

#### **Concept:**
- Use backtracking to place queens in different columns and check for conflicts. Keep track of the rows, columns, and diagonals that are under attack.

#### **Python Solution:**
```python
def solve_n_queens(n):
    def is_safe(board, row, col):
        for i in range(row):
            if board[i] == col or \
               board[i] - i == col - row or \
               board[i] + i == col + row:
                return False
        return True
    
    def solve(board, row):
        if row == n:
            solutions.append(board[:])
            return
        
        for col in range(n):
            if is_safe(board, row, col):
                board[row] = col
                solve(board, row + 1)
                board[row] = -1
    
    solutions = []
    solve([-1] * n, 0)
    return solutions

# Example
n = 4
solutions = solve_n_queens(n)
for solution in solutions:
    print(solution)
```
